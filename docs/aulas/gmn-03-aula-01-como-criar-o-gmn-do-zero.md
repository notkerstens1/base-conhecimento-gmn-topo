# [AULA 01] - Como criar o GMN do Zero

Demonstra o cadastro do Perfil da Empresa: entrada, nome, modelo de atendimento, categoria, endereço, contatos, verificação e complementos. Ao final, o perfil ainda aguarda análise. O exemplo usa dados de teste e muda de cidade para evitar duplicidade; isso não deve virar um procedimento de cadastro fictício. A tese de conta aquecida e vários vínculos facilitarem verificação é opinião do instrutor.
